## What I've been building

- **A deployed PostgreSQL database.** I designed the schema and tables for a departmental dataset, then cleaned and prepared the data with Python and SQL. It's live and in use.
- **A data pipeline for a university office.** It pulled a year of event posts through the Meta Graph API, filtered them with keyword rules and the Gemini API, and turned them into one-page PDF scorecards. The last 6.5 months took about a week instead of an estimated 7 to 8 weeks by hand.
- **Django REST APIs.** On a remote internship I designed the models and built JWT authentication, permissions, pagination and search.
- **Final year project, in progress.** A civic problem-reporting platform for Karachi, built with a team of three. I wrote the Django REST backend and a JavaScript SDK, and I'm helping with the React Native app.
